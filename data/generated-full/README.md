# Full-scale attribution dataset export

Seed: `20261022`.

The CSV and JSON files are generated by `tools/generate_synthetic.py --full --out data/generated-full`. The Java/PostgreSQL run evidence records the matching full-scale run, attribution calculation and quality inspection. The SQL backup is a compressed `pg_dump` of the local `yottaflex_attribution` database, including the append-only starter and full dataset runs and schema. It contains synthetic records only; restore into a disposable PostgreSQL database using the migrations/schema version recorded in the dump.

- Java database run: 500 campaigns, 50,000 contacts, 200,001 touchpoints, 10,000 opportunities, 10,001 orders, 499 cost records.
- Java attribution: 129,610 rows across FIRST_TOUCH, LAST_TOUCH and LINEAR; 30,000 opportunity/model groups; every group sums to 1.000000.
- Java quality validation: all five required anomaly categories detected exactly once.
- Python export validator and same-seed reproducibility checks: passed with zero errors and matching checksums.

Verify the exported files with `SHA256SUMS.txt`.

The unverified anonymous-session example has no contact_id association. The archived PostgreSQL dump was checked and corrected to preserve that rule.
